# selina-electron-vue-demo

Electron + Vue 3, built with [electron-vite](https://electron-vite.org).

Requires Node.js 22.12+.

## Demo

https://github.com/user-attachments/assets/f732ab55-2843-4d1b-a7ea-5779ea345deb

## Install

```
npm install
```

## Run

```
npm run dev
```

## Build

```
npm run build
npm start
```

## Test

```
npm run test:unit
```
